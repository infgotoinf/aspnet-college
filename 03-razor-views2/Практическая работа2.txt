Практическая работа: «Витрина товаров с админ-панелью»
Темы : CSS и Bootstrap в ASP.NET Core; Bundling и minification (built-in); static files middleware;
wwwroot; Bootstrap: grid, components (navbar, cards, modals, alerts).
Фокус: не писать свои стили с нуля, а грамотно подключить и использовать Bootstrap, настроить
работу со статикой и бандлингом, оформить типовые UI-компоненты.
Цель работы
Научиться:
 подключать Bootstrap и свои CSS через static files и bundling/minification;
 использовать сетку (grid) и компоненты Bootstrap (navbar, card, modal, alert);
 правильно размещать файлы в wwwroot и ссылаться на них в Razor;
 понимать, как middleware обслуживает статику и как бандлер собирает файлы.
Задание 1. Настройка проекта и static files
1. Папки в wwwroot (создать структуру):
o css/ — ваши кастомные стили
o js/ — ваши скрипты
o img/ — картинки (заглушки можно взять из интернета или использовать placeholder)
2. Проверка Program.cs:
Убедитесь, что есть app.UseStaticFiles(). Это middleware, которое отдаёт файлы из wwwroot.
3. Подключение стилей в _Layout.cshtml:
Вместо прямого подключения файлов используйте секции и условную логику по окружению:
<environment include="Development">
<link rel="stylesheet" href="~/lib/bootstrap/dist/css/bootstrap.css" />
<link rel="stylesheet" href="~/css/site.css" asp-append-version="true" />
</environment>
<environment exclude="Development">
<link rel="stylesheet" href="~/lib/bootstrap/dist/css/bootstrap.min.css" />
<link rel="stylesheet" href="~/css/site.min.css" asp-append-version="true" />
</environment>
