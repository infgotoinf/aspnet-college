Практическая работа: «Панель администратора с динамическими дашбордами»
Темы : Razor-синтаксис, Layouts, ViewComponents
Общее описание
Создать страницу админ-дашборда с карточками показателей, боковой панелью со сводкой по
трендам и многоуровневым layout.
Фокус — на приёмах Razor: выражения, блоки кода, @functions, секции, условная логика, циклы,
partial-представления и ViewComponent.
Задание 1. Модели и хранилище
1. Создайте модель DashboardCard:
 Id (int)
 Title (string) — заголовок карточки
 Value (decimal) — значение показателя
 Trend (enum: Up, Down, Stable) — динамика
 Unit (string) — единица измерения («руб.», «шт.», «%»)
 Description (string) — пояснение
2. Создайте интерфейс IDashboardRepository:
 GetAllCards() — все карточки
 GetById(int id) — одна карточка
 GetLatest(int count) — последние по Id
3. Реализуйте InMemoryDashboardRepository со статическим списком из 6 карточек (разные тренды,
единицы, значения — включая одно отрицательное). Зарегистрируйте как Singleton в Program.cs.
